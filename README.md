
# 🎓 TRMC Main - College Webpage for BIT

This is the official **TRMC Main** website designed for the BIT college community. The platform offers features like a notice board, community discussions with Facebook-style pagination, and a clean user interface tailored for students and faculty.
 #website of this project  https://trmc-main.onrender.com/


---

## 🚀 Features

### 📰 Notice Board
- Display official notices and announcements
- Support for images and rich text
- Most recent notices highlighted on the homepage
- Mobile-friendly layout for easy access on any device

### 💬 Community Forum
- Facebook-style post feed with **pagination**
- Users can post updates, share ideas, and comment
- Profile pictures displayed alongside posts
- Responsive design for mobile and desktop

### 📱 Responsive UI/UX
- Clean and modern design
- Fully responsive for desktop and mobile screens
- Intuitive navigation with sidebar and header menus

### 🔍 Search & Filter (Planned)
- Search notices and community posts by keywords
- Filter posts by categories or dates
